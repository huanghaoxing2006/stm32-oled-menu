# STM32 OLED 菜单交互系统

基于 STM32F103C8T6 + 0.96 寸 I2C OLED 的多级菜单与时间显示交互 Demo。

> 一个从零手写的嵌入式练手项目：OLED 驱动、软定时时钟、按键消抖、菜单状态机全部独立实现，用于验证 STM32 HAL 库外设开发能力。

## 硬件环境

| 模块 | 型号 / 参数 |
|------|-------------|
| 主控 | STM32F103C8T6（Cortex-M3） |
| 显示 | 0.96 寸 OLED，SSD1306，I2C 接口，7 位地址 `0x3C` |
| 按键 | 5 个独立按键（上拉/下拉输入 + EXTI 外部中断） |
| 调试 | ST-Link 下载 + USART1 串口打印 |
| 工具链 | STM32CubeMX + Keil MDK-ARM |

## 功能说明

- **OLED 驱动**：基于显存（`GRAM[8][128]`）的绘制方案，支持点、字符（8×16 字库）绘制与整屏刷新。
- **双页菜单**：按下 `PA0` 在「标题页」与「时钟页」之间切换。
- **软件时钟**：用 `HAL_GetTick()` 差值实现秒级计时，`时:分:秒` 补零显示，满 24 小时自动归零。
- **时钟修改模式**：可进入编辑状态，逐位修改时/分/秒，正在编辑的位以 500ms 周期闪烁。
- **按键消抖**：外部中断只置标志位，主循环检测到松手后才执行动作，避免抖动误触发。

## 按键定义

| 按键 | 引脚 | 作用 |
|------|------|------|
| KEY_MENU | PA0（上拉） | 切换菜单页 |
| KEY_EDIT | PB10（上拉） | 进入 / 退出时钟修改模式 |
| KEY_SEL | PB11（上拉） | 切换编辑位（秒 → 分 → 时） |
| KEY_DOWN | PB12（下拉） | 当前编辑位数值 -1 |
| KEY_UP | PB13（下拉） | 当前编辑位数值 +1 |

## 引脚接线

| 功能 | 引脚 |
|------|------|
| OLED SCL | PB6（I2C1_SCL） |
| OLED SDA | PB7（I2C1_SDA） |
| OLED VCC | 3.3V |
| OLED GND | GND |

## 使用方式

1. 用 Keil 打开 `MDK-ARM/demo1_bee.uvprojx`。
2. 编译后通过 ST-Link 烧录到开发板。
3. 上电后屏幕显示标题页，按 `PA0` 切换到时钟页。
4. 按 `PB10` 进入修改模式，`PB11` 切换编辑位，`PB12`/`PB13` 加减数值。

## 设计要点

- **显存绘制**：画点只改内存 `OLED_GRAM[page][x] |= (1 << bit)`，最后统一 `OLED_Refresh()` 刷屏，避免单点覆盖。
- **中断与主循环分离**：中断回调只置标志，业务逻辑放主循环处理，保证实时性又便于消抖。
- **I2C 寻址**：OLED 7 位地址 `0x3C`，发送时左移一位得到 8 位写地址 `0x78`。
